# Support and scoped services

## Help with the free software

Read the [usage guide](README.md), then [open an issue](https://github.com/ayushdarmorateam1/importready/issues/new/choose) if something is unclear or broken. Include the environment, settings, and a minimal synthetic example. Community support is best effort.

Please keep real customer files, personal information, credentials, and confidential reports out of public issues. Use [SECURITY.md](SECURITY.md) for vulnerabilities.

## Request a scoped service

Possible requests include:

- Custom validation rules for a known import format.
- A repeatable mapping or cleanup workflow for an agreed CSV shape.
- Integrating the JavaScript core or CLI into an existing application or import check.
- A review of a small, reproducible import failure.

[Open a service inquiry](https://github.com/ayushdarmorateam1/importready/issues/new) describing the desired outcome, source and destination formats, approximate file size, deadline, and whether a synthetic sample is available. Share only non-confidential context initially; ask for a private discussion route if needed.

Availability, deliverables, exclusions, fee, and acceptance criteria must be agreed before work begins. Each inquiry receives an individual scope and quote; the repository does not publish a standing service price or book work automatically.

## Sponsorship

Optional sponsorship, when available, helps maintain the public project: correctness fixes, regression fixtures, documentation, and general improvements. Sponsorship does not include a service contract or a response-time guarantee. Custom work is scoped separately.

The project is free to use under its [MIT license](LICENSE). Suggestions and bug reports are welcome whether or not you sponsor it.
