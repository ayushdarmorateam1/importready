## Introduction

I am building and maintaining **ImportReady**, a small open-source tool for checking CSV files before importing them into another system.

ImportReady runs locally in the browser or through a command-line tool. Its reusable JavaScript core checks CSV structure and explicit column rules, explains issues by line and column, and supports optional repairs with a reviewable result. It preserves values such as leading-zero identifiers and does not upload datasets.

Sponsorship helps me spend time on:

- Correctness fixes and reproducible regression tests for difficult CSV cases.
- Clearer diagnostics, examples, and documentation.
- Accessibility and usability improvements to the browser tool.
- Maintaining the shared core and command-line interface.

The project was developed with AI assistance. My focus is on verified behavior, useful examples, understandable code, and ongoing maintenance.

The software is available under the MIT license. Bug reports, synthetic examples, documentation contributions, and constructive feedback are valuable ways to help too.

Community support is best effort. Sponsorship supports the shared project; custom integrations and other commissioned work require a separate agreed scope.
